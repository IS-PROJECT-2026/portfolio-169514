# Portfolio — Ayana Ndete

A terminal-styled personal portfolio site showcasing projects at the intersection of IoT and AI.

**Live site:** https://is-project-2026.github.io/portfolio-169514/

## Overview

This portfolio uses a terminal/console aesthetic to present my background, projects, skills, and contact information. Built as a static site with no framework dependencies — just semantic HTML, custom CSS, and vanilla JavaScript.

## Featured Projects

- **RAG Capstone** — A retrieval-augmented generation system that grounds LLM responses in real source data to reduce hallucination and improve domain-specific accuracy.
- **Smart Farm (ESP32)** — An IoT monitoring system tracking soil and environmental conditions in real time for small-scale farmers.
- **Security System** — A sensor-driven system combining motion/entry detection with automated alerting.

## Tech Stack

- HTML5 (semantic markup, accessible landmarks)
- CSS3 (custom properties / design tokens, CSS Grid, responsive breakpoints)
- Vanilla JavaScript (no frameworks)
- GitHub Pages (deployment)

## Accessibility

This site includes a skip-to-content link, ARIA labels on all major sections, aria-hidden on decorative elements, and visible focus states for keyboard navigation. Color contrast between text and background meets WCAG AA standards.

## Development Workflow

Built following a full git workflow: feature branches per issue, conventional commits, pull requests into main (branch-protected, no direct commits), and milestone-tracked issues.
